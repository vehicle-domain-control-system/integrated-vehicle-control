# Function 색인 — 기존 선언으로 이동

**U1 / INDEX_ONLY · BEHAVIOR_NOT_DESIGNED.** FN-ID는 탐색 식별자이며 새 API나 구현 완료 수가 아니다. 원형은 아래 기존 Source의 선언을 읽는다. 모든 기존 Source@SHA는 `c60dcf65de52b7fb28e0464d616ba00d350890bb` 기준이다.

[Network 입구](00_START_HERE.md) · [Layer](01_LAYER_MAP.md) · [Node](02_NODE_MAP.md) · [Flow](04_FLOW_INDEX.md)

U0 문서 목록 143/143(116 API 목록 + 27 private 목록)을 보존했다. 실제 Source 재조회에서 기존 `DomainNet_PublishPermission()` 1개를 추가 발견해 **144/144**를 연결했다. API 목록 안의 `BcmNetPriv_OnDomainPermission`, `CisNetPriv_RelayPiPermission`, `VssNetPriv_OnDomainPermission`도 Network-private 경계다. 아래 Layer는 기능 경계이며 모듈 파일의 편집상 위치와 구별한다.

[누락 Source: 기존 3개 + 추가 1개](#missing-source) · [다른 선언 근거의 지위](#source-evidence). 각 행의 모듈로 돌아가면 현재 함수 Source와 향후 별도 파일 위치를 찾을 수 있다. 상세 파일은 아직 생성하지 않았다.

<a id="source-evidence"></a>
## 다른 선언 근거의 지위

U0 전체 인벤토리 244행은 문서143 + 실제 Header 메타27 + 실제 Header API54 + 누락 Header3 + 첨부 I1 Header API17이다. 이번 144행은 문서 출처만 재탐색한 결과이며 나머지를 구현 함수로 합산하지 않는다.

[기존 Domain_Interface_v0.5.h](../../Domain/architecture/2_Domain_interface/Domain_Interface_v0.5.h)의 API41은 문서의 C2 target72와 다른 snapshot이다. [기존 Gateway_Interface.h](../../esp32/3_Gateway_Interface/Gateway_Interface.h)의 API13도 누락된 DECLARED_HEADERS 원본과 버전/원형 동일성을 확정하지 않는다. 나머지25개 실제 Header는 owner 구현 참고 파일 메타이며 새 함수 대상이 아니다. 첨부 I1 Header API17은 과거 Host 후보의 선언 참고로, 현재 Git 함수 링크 또는 새 실행 성공으로 표시하지 않는다.

원 계약·함수명·인자는 변경하지 않았다. `DECLARED_SOURCE`는 기존 문서의 선언 지위이며 현재 헤더 복구·Firmware 연결을 뜻하지 않는다. 팀 Wire·mm/cm·enum·Permission 원 Producer/150 ms `SOURCE_LIMIT_NOT_AGREED`·SDK/HW/time은 [팀 OPEN](../interface/06_OPEN_FOR_TEAM.md)을 따른다.
