# BCM

BCM 관련 요구사항, 기능 정의, 인터페이스 및 구현 설계 문서를 관리한다.

담당 기능:

- 도어 잠금 제어 (Smart Access)
- 실내 환경 제어 (Predictive Climate)
- 실내 조명 제어 (Ambient Lighting)

초기 작성 대상:

- 기능 범위 및 기능 경계
- 입력 조건 및 확정된 상태
- 액추에이터 구동 및 구동 결과 확인
- 표시 우선순위 정책
- Network 연계 신호
- Fault / 안전 차단 정책
- 상위 시스템 연계 원칙

구체적인 스펙은 SR 검토 이후 확정한다.
