# Repository Setup Checklist

새 GitHub Repository 생성 후 한 번만 확인한다.

## Repository

- [ ] 기본 브랜치가 `main`인지 확인
- [ ] README 반영
- [ ] 협업 가이드 반영
- [ ] Issue Template 반영
- [ ] Pull Request Template 반영

## main Branch Protection

권장 초기 설정:

- [ ] Pull Request를 통해서만 Merge
- [ ] 최소 1명 Approval
- [ ] Review conversation 해결 후 Merge
- [ ] Force Push 금지

## Merge 방식

- [ ] `Squash and merge` 사용 여부 팀 합의

## 팀원

- [ ] Organization / Repository 멤버 초대
- [ ] 권한 확인
- [ ] 각 담당 영역 확인

## 초기 문서

- [ ] SR 작성 시작
- [ ] Architecture 초안 작성
- [ ] Network 초안 작성
- [ ] VSS 초안 작성
