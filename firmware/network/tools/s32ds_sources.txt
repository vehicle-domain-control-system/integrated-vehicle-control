# Product sources of the node builds: the RTD backend build of an S32DS board
# project and the per-node Network bundles.
# One entry per line, relative to firmware/network. '#' starts a comment.
#     <path>   @NODE ...        NODE: VSS CIS BCM DOMAIN (tags are optional on .c)
# - A .c line without a tag belongs to every node. A tagged .c line belongs
#   only to the nodes it names.
# - A .h line must carry tags: that header belongs only to the named nodes.
#   Every header that is not listed is common: include/network/** (except the
#   host headers net_host_mock.h and net_virtual.h) and the *.h files of the
#   folders of the selected .c files.
# - An unknown or repeated tag, a header line without a tag, a path listed
#   twice or one of the characters semicolon and square brackets is an error
#   for every reader (tools/source_list.py and tools/s32ds_sources.cmake
#   implement the same rules). A listed file that does not exist: CMake stops
#   (FATAL_ERROR), sync_to_s32ds.py refuses (exit 1), sdk_swap_check.py fails
#   when it compiles the file.
# Readers:
# - CMakeLists.txt (NETWORK_BUILD_RTD_MOCK): compiles and links on host the
#   untagged .c files and the .c files tagged with the build's node profile.
# - tools/sync_to_s32ds.py --node NODE: the bundle of that node (same .c
#   selection, headers as above, the node's board folder, README.md).
# - tools/sync_to_s32ds.py --project and tools/sdk_swap_check.py: every .c
#   except the DOMAIN-only ones (the board project copy, headers untagged).
# Never copy sdk_mock/, tests/, tools/.
